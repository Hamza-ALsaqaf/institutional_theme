# Font licence record

Every font file shipped by the Institutional Theme, with its source and licence. All files are unmodified upstream files: the private CSS family names (`Midad ...`) live in the stylesheets under `public/scss/fonts/`, never inside the files. IBM Plex declares the Reserved Font Name "Plex" in its licence; the files are not renamed or altered here.

Kind of file: WOFF2 files are the screen subsets (Latin or Arabic) published by Fontsource, built from the Google Fonts releases of each family. TrueType files are used only for print, where wkhtmltopdf cannot read WOFF2. Bundled paths are relative to `institutional_theme/public/fonts/` and are served at `/assets/institutional_theme/fonts/`.

|---|---|

| TrueType files for Noto and Tajawal | Print uses the Plex TrueType files for those pairings (ADR 0004). |
| Tajawal weight 600 | Tajawal 5.3.0 has no 600; the 700 file answers 600 and 700 (`font-weight: 600 700`). |
| IBM Plex Mono weight 600 | Not shipped; requests resolve to the 500 face and nothing is synthesised. |
