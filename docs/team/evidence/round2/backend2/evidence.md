## Decisions

1. Banner module (`shell/banner.js`) is shared; one element per kind, found again on every call, handler on the button this module creates. Contract markup exactly as fixed by the lead.
2. Idle warning does not clear on input once shown; only the button does (input would not refresh the session, a request does). Wording says the session "may" end, because background requests also refresh it.
3. Realtime `disconnect` with reason "io client disconnect" is ignored (the page closed it). A banner for a realtime drop shows a different text from the offline one, under the same `data-ins-banner="offline"`.
4. Masked static value is made focusable (`tabindex="0"`) so assistive technology and keyboard reach the reason. It adds one tab stop per masked field.
5. Budgets: a missing build skips, an unknown bundle fails, the excess of a bundle needs an entry in `JUSTIFIED`.
6. `except Exception` in `bench_dist` (ruff on Python 3.14 rewrites a tuple `except` to the unparenthesised form, which Python 3.12 rejects; the audits run anywhere).
